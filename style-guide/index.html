03 / GET STARTED

一份 CSS，直接接入。

无需安装框架。引入样式后，在页面外层添加 hikcc-theme，组件使用 hikcc-* 类名。

<link rel="stylesheet"
  href="https://hikcc.top/assets/hikcc-ui.css?v=1">

<body class="hikcc-theme">
  <main class="hikcc-container">
    <article class="hikcc-surface">
      <h1>你的页面标题</h1>
      <p>清晰的内容，统一的风格。</p>
      <a class="hikcc-button hikcc-button-primary"
         href="/">返回首页</a>
    </article>
  </main>
</body>

生产项目建议下载并固定版本。可以覆盖 --hikcc-* 变量调整颜色；导航展开、搜索等业务行为由各项目实现。
