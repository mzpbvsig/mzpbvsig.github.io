## 关于

这个仓库保存 HiKcc. 的公开网站生成产物。HiKcc. 是一个基于原始证据的 AI 研究档案；文章会区分逐字引用与实践转述，并让主要结论能够回溯到原始来源。

网站由 [mzpbvsig/hikcc](https://github.com/mzpbvsig/hikcc) 自动构建和发布。HTML 与静态资源应在源仓库修改，不要直接编辑这里的生成文件。
