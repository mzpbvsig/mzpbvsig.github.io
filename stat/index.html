这些数字如何计算

Token 来源为 Codex 个人统计页所使用的账号接口。累计、峰值、连续天数与最长聊天时长直接采用官方字段；每天的 token 使用官方返回的日期，不按本地时区重新分组。

账号统计与本机会话日志的覆盖范围不同，本页以账号统计为准。官方接口未提供每日输入、缓存和输出拆分，因此此页不展示这些拆分，也不换算额度或费用。

这是官方数据的导出快照，不是实时查询账号。刷新网页只会读取已发布数据；更新需重新同步。官方服务自身也可能有统计延迟。

访问统计覆盖本站已接入计数的页面。访问计数数据库仅保存随机访问标识、匿名浏览器标识的哈希和日期，不保存 IP、页面地址或会话正文。清除浏览器存储、更换设备或跨域访问可能重复计算访客；隐私偏好、拦截器和禁用脚本可能漏记，机器人也可能影响计数。UV 是浏览器访客估计，不是精确人数。
