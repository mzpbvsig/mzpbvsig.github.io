这些数字如何计算

Token 按北京时间（UTC+8）归日，以本机 Codex 会话与归档中的用量事件为依据。使用累计用量的增量去重，避免重复累计；记录发生在哪一天，就计入哪一天。没有记录的日期显示为“未记录”，不代表实际用量一定为零。

总 token = 输入 + 输出。缓存输入已包含在输入中，推理输出已包含在输出中，不能再加一次。这里展示 token 用量，不换算订阅额度或费用。

这是导出的统计快照，刷新网页只会读取已发布数据，不会读取你的电脑。更新需要重新导出并发布；当前仍在进行的会话只统计到导出时间。

访问统计覆盖本站已接入计数的页面。服务器仅保存随机访问标识、匿名浏览器标识的哈希和日期，不保存 IP、页面地址或会话正文。清除浏览器存储、更换设备或跨域访问可能重复计算访客；隐私偏好、拦截器和禁用脚本可能漏记，机器人也可能影响计数。因此 UV 是浏览器访客估计，不是精确人数。
